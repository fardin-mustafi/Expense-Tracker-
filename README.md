# 💰 Financial Bestie

### Smart Personal Finance & Wealth Tracker

Financial Bestie is a personal finance management web application designed to help students and young professionals manage their daily financial activities from one place.

The system provides features for expense management, wallets, budgets, savings, analytics, transaction history, and charitable giving.

> 🎓 Developed as part of our Web Programming Lab course.

---

## ✨ Features

- 💳 **Multi-Wallet Management** — Manage different wallets such as Cash, bKash, Nagad, Rocket, and Bank.
- 🧾 **Expense Tracking** — Record and manage daily expenses.
- 📊 **Spending Analytics** — Visualize spending patterns and financial activities.
- 🎯 **Budget Management** — Set budgets and monitor spending.
- 🏦 **Savings Management** — Create and manage savings goals.
- 🤲 **Sadaqa & Charity Tracker** — Track charitable donations and Sadaqa.
- 🔍 **Transaction Search** — Search and manage transaction information.
- ⚙️ **Settings** — Manage application preferences and settings.
- 🤖 **AI Bestie** — An intelligent finance assistant interface for financial guidance.
