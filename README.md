# 💰 Financial Bestie

### Smart Personal Finance & Wealth Tracker

Financial Bestie is a personal finance management web application designed to help students and young professionals manage their daily expenses, wallets, budgets, savings, transactions, and charitable activities from one platform.

> 🎓 Developed as a Web Programming Lab project.

---

## ✨ Features

- 💳 **Multi-Wallet Management**  
  Manage multiple wallets including Cash, bKash, Nagad, Rocket, and Bank.

- 🧾 **Expense Tracking**  
  Record and manage daily expenses with categories, amounts, wallets, and notes.

- 📊 **Spending Analytics**  
  Analyze spending patterns using charts and financial statistics.

- 🎯 **Budget Management**  
  Set spending limits and monitor budget progress.

- 🏦 **Savings Management**  
  Create savings goals and track financial progress.

- 🤲 **Sadaqa & Charity Tracker**  
  Record Sadaqa, donations, and charitable contributions.

- 🔍 **Transaction Search**  
  Search and manage transaction records easily.

- ⚙️ **Settings**  
  Manage application preferences and user settings.

- 🤖 **AI Bestie**  
  Provides an interactive interface for future AI-powered financial assistance.
